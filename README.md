# sine_vedio — สายพานผลิตคลิป Shopee Video

ทำคลิปแนวตั้ง 15 วินาทีสำหรับ Shopee Affiliate โดยใช้ Google Flow (Veo) สร้างช็อตคนพูด
รูปถ่ายสินค้าจริงสำหรับ b-roll แล้วประกอบ ใส่ซับไทย ใส่เพลง ด้วย ffmpeg

## หลักการสำคัญ

**AI สร้างเฉพาะช็อตคนพูด ตัวสินค้าใช้รูปถ่ายจริงเสมอ**

โมเดลสร้างวีดีโอจะ "ตีความ" ตัวสินค้าใหม่ ฉลากเพี้ยน โลโก้มั่ว สีไม่ตรง
สำหรับงาน affiliate นั่นแปลว่าคนกดลิงก์เข้าไปเจอของไม่เหมือนในคลิป
→ ยอดคืนสินค้าพุ่ง → เสี่ยงโดนตัดค่าคอมหรือปิดบัญชี

เพราะงั้นแบ่งเป็น 3 ชั้น:

| ชั้น | เนื้อหา | สร้างด้วย |
|---|---|---|
| 1 | คนพูด (hook + CTA) | Google Flow (Veo) จากรูปหน้าคุณเอง |
| 2 | สินค้า | รูปถ่ายจริง + Ken Burns จาก `tools/build.py` |
| 3 | ซับ เพลง การประกอบ | `tools/` ในรีโปนี้ (ฟรี ไม่ต้องต่อเน็ต) |

## ติดตั้ง

```bash
./setup.sh
```

ลง `imageio-ffmpeg` กับ `pyyaml` แล้วตรวจว่าเจอ ffmpeg และฟอนต์ไทยครบ
ฟอนต์ Noto Sans Thai กับ IBM Plex Sans Thai อยู่ใน `assets/fonts/` แล้ว ไม่ต้องโหลดเพิ่ม

## ขั้นตอนทำคลิปหนึ่งตัว

### 1. เตรียมรูป

```
assets/person/          รูปหน้าตรงของคุณ 1-3 รูป (ใช้อัปเข้า Flow)
assets/product/         รูปสินค้าจริง อย่างน้อย 2 รูป (มุมรวม + close-up)
assets/music/bg.mp3     เพลงประกอบ ถ้าต้องการ
```

รูปสินค้าเอาจากหน้าร้าน Shopee ได้ แต่เลือกรูปความละเอียดสูง
ถ้าเป็นรูปแนวนอนก็ใช้ได้ สคริปต์จะครอปเป็นแนวตั้งให้เอง

### 2. เขียนบท

เปิด `prompts/script-formulas.md` เลือกสูตร A / B / C แล้วเติมข้อมูลสินค้า

### 3. สร้างช็อตคนพูดใน Flow

เปิด `prompts/flow-veo.md` ก๊อป prompt ไปวางใน Flow อัปรูปหน้าคุณเป็น reference
render 2 ช็อต แล้วโหลดมาวางที่:

```
projects/<ชื่องาน>/raw/01-hook.mp4
projects/<ชื่องาน>/raw/02-cta.mp4
```

### 4. ตั้งค่าโครงคลิป

```bash
cp -r projects/_template projects/earbuds-01
```

แก้ `projects/earbuds-01/shots.yaml` ให้ path ชี้ไปที่ไฟล์จริง
ปรับ `start` / `duration` ให้ได้จังหวะที่ชอบ รวมกันให้ได้ 15 วินาที

### 5. เขียนซับ

แก้ `projects/earbuds-01/subs.txt` รูปแบบคือ `เริ่ม-จบ | ข้อความ`
คำที่อยู่ใน `*ดอกจัน*` จะถูกเน้นสี แล้วแปลงเป็น `.ass`:

```bash
python3 tools/make_ass.py projects/earbuds-01/subs.txt -o projects/earbuds-01/subs.ass
```

ปรับหน้าตาได้ด้วย `--font` `--size` `--highlight` `--margin-v`
(`python3 tools/make_ass.py --help` ดูทั้งหมด)

### 6. ประกอบ

```bash
python3 tools/build.py projects/earbuds-01
```

ได้ไฟล์ที่ `projects/earbuds-01/out/final.mp4` — 1080x1920, H.264, พร้อมอัป

เติม `--dry-run` ถ้าอยากเห็นคำสั่ง ffmpeg เฉย ๆ ไม่ต้อง render

## ตัดคลิปรวม moment ตามท่อนเพลง (`tools/moments.py`)

ใช้กับวีดีโอที่ถ่ายเองทั้งโฟลเดอร์ เช่น รวม moment น่ารักของลูก ใส่เพลงยาว 22 วินาที
สคริปต์นี้รันบนเครื่องที่มีไฟล์วีดีโออยู่ (เช่น Mac ของคุณ) หลังรัน `./setup.sh` แล้ว

**1. สแกนโฟลเดอร์** แล้วทำ contact sheet ของแต่ละคลิป

```bash
python3 tools/moments.py scan ~/Downloads/LEON --project projects/LEON_2_OCT
```

ได้ `projects/LEON_2_OCT/sheets/V01.jpg`, `V02.jpg`, ... แต่ละช่องคือ 1 เฟรม
มีเลขคลิปกับวินาทีกำกับ (คลิปยาวจะเว้นช่วงห่างขึ้น ไม่เกิน 36 ช่องต่อคลิป)

**2. เลือก moment** — ส่งรูปใน `sheets/` ให้ Claude เลือกช่วงที่น่ารัก หรือเลือกเอง
แล้วเขียนลง `projects/LEON_2_OCT/plan.txt` บรรทัดละช็อต รวมให้ได้ 22 วินาทีพอดี

```
V03  12.0  2.5   # หัวเราะ
V07   4.0  3.0   # ทำหน้าบึ้ง
```

**3. ตัดต่อ** ใส่เพลงโดยเริ่มที่ท่อนที่ต้องการ (`--music-start` เป็นวินาทีในเพลง)

```bash
python3 tools/moments.py cut --project projects/LEON_2_OCT \
    --music ~/Downloads/ยิ้มอันตราย.mp3 --music-start 45
```

ได้ `projects/LEON_2_OCT/out/final.mp4` (1080x1920 เสียงเพลงอย่างเดียว ตัดเสียงในคลิปออก)
เปิด CapCut → New project → import `final.mp4` แล้วตั้งชื่อโปรเจกต์ `LEON_2_OCT`
จะใส่สติกเกอร์ ข้อความ หรือขยับจังหวะให้ตรงบีตต่อในนั้นได้

คลิปแนวนอนจะถูกครอปตรงกลางให้เป็นแนวตั้ง ถ้าตัวลูกอยู่ชิดขอบเฟรม
ให้เลือกช่วงอื่น หรือไปขยับเฟรมเองใน CapCut

## โครงไฟล์

```
assets/fonts/       ฟอนต์ไทย (อยู่ใน git)
assets/person/      รูปหน้าคุณ (ไม่อยู่ใน git)
assets/product/     รูปสินค้า (ไม่อยู่ใน git)
assets/music/       เพลงประกอบ (ไม่อยู่ใน git)
prompts/            คู่มือเขียนบทและ prompt สำหรับ Flow
projects/_template/ แม่แบบงาน ก๊อปไปใช้ต่อ
projects/<งาน>/     งานจริงแต่ละคลิป
tools/build.py      ประกอบคลิป
tools/make_ass.py   สร้างซับ .ass
tools/moments.py    contact sheet + ตัดคลิปรวม moment ตามเพลง
```

ไฟล์วีดีโอกับรูปไม่ถูก commit (ดู `.gitignore`) — git เก็บแต่บท ซับ และค่าตั้ง
ซึ่งเป็นส่วนที่อยากเก็บประวัติจริง ๆ

## ข้อจำกัดที่ควรรู้

- **ตัดคำภาษาไทย**: ไทยไม่เว้นวรรคระหว่างคำ ซับเลยแสดงทีละวลีตามที่เขียนใน
  `subs.txt` ไม่ใช่เด้งทีละคำแบบซับอังกฤษ — อ่านง่ายกว่าบนมือถืออยู่แล้ว
- **`build.py` ใช้ hard cut** ระหว่างช็อต ไม่มี transition ซึ่งเป็นสไตล์ UGC
  ที่เข้ากับ Shopee Video อยู่แล้ว ถ้าอยากได้ crossfade ต้องแก้ filter graph เพิ่ม
- **ไม่มี `drawtext`**: ffmpeg static build ที่ใช้ไม่มี libfreetype ข้อความทุกอย่าง
  จึงทำผ่าน `.ass` (libass) ซึ่งจัดวางภาษาไทยได้ดีกว่าอยู่แล้ว

## เรื่องที่ต้องทำตามกฎ

- ใช้รูปหน้า**ตัวเอง**เท่านั้นในการสร้าง avatar
- ติด `#affiliate` หรือ `#ได้รับค่าคอมมิชชัน` ทุกคลิป
- ติดป้าย AI-generated ตอนอัป — คลิปจาก Veo ฝัง SynthID มาอยู่แล้ว ระบบตรวจเจอ
- อย่าอ้างสรรพคุณเกินจริง โดยเฉพาะของกิน อาหารเสริม เครื่องสำอาง
